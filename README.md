# Meridex Solutions - Dark Mode Edition

Premium administrative and financial operations outsourcing platform for mortgage brokers, insurance brokerages, and accounting practices across Australia, the United States, and the United Kingdom.

## Tech Stack
- **Framework:** Next.js 16 (App Router & Turbopack)
- **UI & Styling:** React 19, TypeScript, Tailwind CSS v4
- **Email Delivery:** Nodemailer with Hostinger Native SMTP (SSL 465)
- **Icons:** Lucide React

## Development
```bash
npm run dev
```

## Production Build
```bash
npm run build
```
